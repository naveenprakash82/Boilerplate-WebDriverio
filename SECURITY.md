# Security policy

This repository contains experimental test analysis examples and is not a hosted service.

## Reporting security issues

Do not disclose credentials, exploitable private systems, or sensitive test artifacts in public GitHub issues. Contact the repository maintainer privately through the contact options on their GitHub profile before sharing vulnerability details.

For ordinary bugs and reproducible compatibility problems, open a GitHub issue with a synthetic example.

## Scope

No external service credentials are required for the documented synthetic examples. Do not run untrusted reports or third-party scripts in a privileged CI environment without reviewing their contents and permissions.
