# v1.1.0 — Test reliability analysis

**Release type:** Pre-release.

## What's included

- Multi-run analysis of supported Jest and Playwright JSON reports with per-test observation coverage, missing run identifiers, and insufficient-evidence signals.
- Duplicate report-path detection, including symlink aliases, and warnings for byte-identical distinct reports.
- Descriptive pass/fail/skip summaries and a transparent dependency-based investigation ranking heuristic.
- Synthetic browser checkout and consumer API contract examples, regression tests, and JavaScript syntax checks.
- MIT licensing, contributor guidance, security reporting instructions, and usage documentation.

## Try it

Requires Node.js 18 or later and npm. Chrome/Chromium is needed for browser tests.

```bash
npm install
npm run check
npm run test:unit
npm run analyze -- examples/sample-runs.json
npm run analyze:batch -- jest ci-001 examples/sample-jest-results.json ci-002 examples/sample-jest-results-run2.json
```

For browser integration examples, run `npm test`. See [the getting started walkthrough](../GETTING_STARTED.md) and [batch analysis guide](../batch-analysis.md).

## Known limitations

- No calibrated failure predictions, automatically inferred dependencies, or automated remediation.
- Jest and Playwright JSON adapters support documented subsets, not all reporter versions.
- No npm package is published; the repository package is marked private.
- Use synthetic or permission-cleared test reports only.
